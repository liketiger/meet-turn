# Pretendard

The bundled Pretendard font files are sourced from the official
[`orioncactus/pretendard`](https://github.com/orioncactus/pretendard) repository,
version 1.3.9, and are distributed under the SIL Open Font License 1.1.

The application registers the following static weights through `expo-font`:

- Pretendard Regular (400)
- Pretendard Medium (500)
- Pretendard SemiBold (600)
- Pretendard Bold (700)
